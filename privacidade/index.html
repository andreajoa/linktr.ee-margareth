Política de Privacidade

Esta página explica como os dados de navegação são usados para melhorar os conteúdos e os caminhos oferecidos por Margareth Almeida.

O que é coletado

Somente após sua autorização, registramos visitas, tempo ativo aproximado, profundidade de rolagem, links clicados, origem da visita, campanha, tipo de dispositivo, navegador e localização aproximada informada pela infraestrutura de hospedagem.

Não armazenamos endereço IP, nome, e-mail, telefone ou localização exata neste sistema de métricas.

Para que usamos

Os dados servem para entender quais conteúdos são mais úteis, identificar dificuldades de navegação e melhorar páginas, ofertas e chamadas para ação. Os registros técnicos são mantidos por até 180 dias.
